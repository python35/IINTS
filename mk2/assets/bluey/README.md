# Bluey Assets

These images are retained as part of the MK.2 Calm Mode prototype at the
project author's request. The `source` directory contains the supplied images;
the `generated` directory contains the 64x64 RGB565 versions used by the Pico.

Bluey is a third-party character. These character images are not covered by
the repository's MIT license, and all rights remain with their respective
rights holders. This research project is not affiliated with or endorsed by
those rights holders.
