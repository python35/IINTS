# Pico Deploy Folder

Copy the runtime files in this directory to the root of the Pico filesystem;
this `README.md` itself is not required there. The included `pico_app.mpy` was
compiled from `../pico_drv8833_correct_pins.py` and tested with MicroPython
1.28.0.

Do not test motor delivery with insulin connected. This build is a research
prototype and has not been clinically validated.
